# TERRA — Israel Training Market

Русскоязычный дашборд рынка курсов инструкторов тренажёрного зала и массажистов в Израиле: карта 12 локаций и 6 округов, стратегии RU / HE / AR, конкуренты, 16 источников и сценарная рентабельность.

## Локальный запуск

После распаковки установите Bun и выполните `bun install --frozen-lockfile`. Создайте `.env` из `.env.template`; для локальной базы укажите `DATABASE_URL=file:./local.db`, затем запустите `bun run dev`. Веб-интерфейс: `http://localhost:4200`. Полная инструкция находится в README внутри архива.
